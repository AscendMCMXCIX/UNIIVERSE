# Draft Intelligence research (isolated)

Offline research for the Draft Intelligence plan, Phases 0 and 1 only. It is **not part of
UNIIVERSE**: nothing here is imported by the app, built, deployed or connected to the production
database, and it makes no Riot API request. It lives on the `research/draft-intelligence` branch,
which is never merged without the owner's approval.

- The protocol was frozen before any result: [PROTOCOL.md](PROTOCOL.md).
- Results: [results/REPORT.md](results/REPORT.md), generated by the scripts.

## Running it

Python 3.11 with `requirements.txt`, in a virtual environment outside the app:

```
python3 -m venv /path/to/venv && /path/to/venv/bin/pip install -r requirements.txt
git clone --depth 1 https://github.com/DeusExMachina1993/lol-draft /path/to/lol-draft   # commit 447d68c
/path/to/venv/bin/python src/run_all.py --data /path/to/lol-draft --out results
```

The dataset (about 600 MB) is never copied into this repository.

## Optional team export (RQ6)

The team-specific question needs the members' own games, which only the owner can export. Nothing
here depends on it. If supplied:

- one CSV, run in the Supabase SQL editor with `export/team_games.sql`;
- the file carries pseudonyms only (`p1`, `p2` …), the same as `data-audit` uses, and no Riot ID, PUUID or non-member data;
- it stays out of git (`.gitignore`).
